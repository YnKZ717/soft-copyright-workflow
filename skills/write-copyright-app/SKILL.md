# 著作权申请表撰写技能

当用户需要填写著作权申请表时触发。

## 触发条件

- 用户说"写著作权申请表"、"生成著作权申请表"、"帮我填申请表"
- 用户通过 `/write-copyright-application` 命令触发
- 被 `copyright-workflow` 全流程调用

## 执行流程

### Step 1：确认信息

**优先使用 `collect-info` 已收集的信息。** 如果未收集，则询问：

**使用 AskUserQuestion 提供选择题，每个问题必须包含：预设选项 + 跳过 + 自定义输入。**

| 信息项 | 必须 | 说明 |
|--------|------|------|
| 软件全称 | ✅ | 格式：Neowow + 功能 + 系统/软件 |
| 软件简称 | 可选 | 简短有辨识度 |
| 版本号 | ✅ | 首次申请 V1.0 |
| 软件完成日期 | ✅ | 必须晚于公司成立日≥6个月 |
| 软件发表日期 | ✅ | 必须晚于完成日期 |
| 开发目的 | ✅ | ≥8字 |
| 面向领域/行业 | ✅ | ≥4字 |
| 编程语言 | ✅ | 从标准列表选择 |
| 源程序量 | ✅ | 实际代码行数 |
| 主要功能描述 | ✅ | 500-1300字（AI辅助生成） |
| 技术特点 | ✅ | ≤100字（AI辅助生成） |
| 软件技术特点类型 | ✅ | 选1-3项 |

**固定信息（自动填充，无需询问）：**
- 公司成立日期：{{company.founding_date}}
- 公司名称：{{company.name}}
- 统一社会信用代码：{{company.credit_code}}
- 发表城市：{{company.publish_city}}

### Step 2：AI 生成核心内容

**主要功能（500-1300字）结构：**
```
[首段：核心业务流程一句话概括]
本软件的核心业务流程为：{输入}→{处理}→{输出}。

[第二段：总体概述]
本软件是一款应用于{领域}的{软件类型}，核心功能是{一句话概括}。
系统采用{技术架构}，集成{能力列举}，为用户提供{价值}。

[第三段起：功能详述]
软件功能涵盖以下方面：
• {功能模块1}：{描述}
• {功能模块2}：{描述}
• ...

[末段：价值总结]
通过上述功能，本软件实现了{成果}，适用于{场景}等场景。
```

**禁止"首先…其次…此外…最后"四段式。**

**技术特点（≤100字）：**
```
采用{架构模式}架构，基于{后端技术}，
以{数据库}为存储、{缓存}为缓存，
通过{核心能力}，{达成效果}。
```

### Step 3：生成 Word 文档

**文档结构：**
```
[标题] 计算机软件著作权登记申请表 (18pt加粗居中)
[副标题] （{软件全称} {版本号}）(12pt居中)

[表格] 25行×2列，居中
│   ├── Row 0: 一、软件基本信息（表头，蓝色背景#D9E2F3）
│   ├── Row 1-21: 各字段及值
│   ├── Row 22: 二、著作权人（表头，蓝色背景）
│   └── Row 23-24: 公司名称 + 统一社会信用代码
```

**重要规范：**
- 不包含"请您认真填写表格，提交之后无法修改！"
- 整个表格必须水平居中
- 案件编号永远留空
- 版本号用大写 V（V1.0 不是 v1.0）
- 表格属性设置参考 `references/table-style.md`

### Step 4：CMMI3 审查

生成后**自动调用 `cmmi3-review`** 审查：
- 主要功能 500-1300 字？
- 技术特点 ≤100 字？
- 日期逻辑合理？
- 软件名称格式正确？

审查不通过 → 自动修正 → 重新审查

### Step 5：保存文件

**保存位置：** `result\` 目录（在 `collect-info` 确认的输出路径下）

**命名格式：** `{软件全称}V{版本号}-著作权申请表.docx`

**异色字体标注：** 如果该字段来自 AI 代决策，必须根据 `ai_decisions` 中的风险等级设置字体颜色：
- 低风险 → 蓝色 `RGB(0x2E, 0x86, 0xC1)`
- 中风险 → 橙色 `RGB(0xE6, 0x95, 0x2A)`
- 高风险 → 红色 `RGB(0xC0, 0x39, 0x2B)`
## 行为约束

### 必须做到
- ✅ 主要功能必须与说明书、源代码保持一致
- ✅ 公司固定信息不要每次询问，直接使用
- ✅ 生成后自动调用 cmmi3-review

### 禁止做到
- ❌ 使用"首先…其次…此外…最后"四段式
- ❌ 案件编号填写任何内容
-  版本号用小写 v
