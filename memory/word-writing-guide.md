# Word 文档撰写规范

**来源：** 参照 `{{template_dir}}\` 中的所有文档模板提炼。

## 核心格式标准

### 字体与字号（EMU 换算：1pt = 12700 EMU）

| 用途 | 字体 | 字号(pt) | EMU值 | 加粗 | 对齐 |
|------|------|----------|-------|------|------|
| 大标题（封面） | 宋体 | 36pt | 457200 | 是 | 居中 |
| 文档标题 | 微软雅黑 | 18pt | 228600 | 是 | 居中 |
| 章节标题 | 宋体/微软雅黑 | 14pt | 177800 | 是 | 左对齐/两端对齐 |
| 正文内容 | 宋体/微软雅黑 | 14pt | 177800 | 否 | 两端对齐/左对齐 |
| 说明文字 | 微软雅黑 | 12pt | 152400 | 否 | 左对齐 |
| 注释/图片说明 | 宋体 | 14pt | 177800 | 否 | 居中 |

### 页面设置

| 文档类型 | 上边距 | 下边距 | 左边距 | 右边距 |
|----------|--------|--------|--------|--------|
| 说明书 | 647700 (≈1.7cm) | 914400 (2.54cm) | 575945 (≈1.5cm) | 685800 (≈1.8cm) |
| 注意事项 | 914400 (2.54cm) | 914400 (2.54cm) | 1143000 (3cm) | 1143000 (3cm) |
| 申请表 | 360045 (≈1cm) | 360045 (≈1cm) | 360045 (≈1cm) | 360045 (≈1cm) |

### 文档结构模板

#### 使用说明书结构
```
[封面] 软件全称V1.0 (宋体 36pt 加粗 居中)
[封面] 使用说明书 (宋体 36pt 加粗 居中)
[正文] 系统简介 (宋体 14pt 两端对齐)
[正文] 登录 (宋体 14pt 加粗)
  → 描述登录步骤
[正文] 一级功能模块 (宋体 14pt 加粗)
  [正文] 二级功能 (宋体 14pt 加粗)
    → 操作描述 (宋体 14pt)
    → [截图]
    → 截图说明 (宋体 14pt 居中)
    → 字段说明列表 (宋体 14pt)
```

#### 注意事项文档结构
```
[标题] 注意事项 (微软雅黑 18pt 加粗 居中)
[小节] 说明书： (微软雅黑 14pt 加粗)
  → 说明条目 (微软雅黑 12pt)
[小节] 源代码： (微软雅黑 14pt 加粗)
  → 说明条目 (微软雅黑 12pt)
[小节] 申请表： (微软雅黑 14pt 加粗)
  → 说明条目 (微软雅黑 12pt)
```

### 写作规范
- **不出现目录**
- 每个截图都必须有对应文字描述
- 截图中的软件名称需与申请全称/简称一致
- 截图时间需晚于开发完成时间
- 截图不要出现第三方信息
- 说明书功能需与申请表主要功能描述一致
- 代码功能需与说明书对应匹配
- 操作描述格式：「在导航栏点击 <模块名>，然后点击左侧的 <功能名> 将显示...」
- 字段说明格式：「字段名：字段说明」

### 文档保存规则 ⚠️ 重要

**每次修改现有文档时，直接覆盖原文件保存，不要创建_temp或任何新文件名。**

**Why:** 用户明确表示"不要创建新文档了，下一次更改直接覆盖"，创建_temp文件增加了用户的重命名负担。
**How to apply:** 使用 python-docx 修改文档后，直接 `doc.save(原路径)` 覆盖原文件。如果文件被 Word 占用导致保存失败，提示用户关闭 Word 后重试。

### python-docx 代码模板
```python
from docx import Document
from docx.shared import Pt, Emu
from docx.enum.text import WD_ALIGN_PARAGRAPH

doc = Document()

# 封面标题
title = doc.add_paragraph()
title.alignment = WD_ALIGN_PARAGRAPH.CENTER
run = title.add_run('软件名称V1.0')
run.font.name = '宋体'
run.font.size = Pt(36)
run.bold = True

# 章节标题
heading = doc.add_paragraph()
run = heading.add_run('系统简介')
run.font.name = '宋体'
run.font.size = Pt(14)
run.bold = True

# 正文
body = doc.add_paragraph()
body.alignment = WD_ALIGN_PARAGRAPH.JUSTIFY
run = body.add_run('正文内容...')
run.font.name = '宋体'
run.font.size = Pt(14)
```

### 自动清理

**每次文档生成完成后，必须自动删除生成过程中使用的临时 .py 脚本文件。** 不需要询问用户，直接删除。

### 图片替换

**图表生成后，替换文档中的图片由用户自行完成。** Claude 只负责生成/修改图表 PNG 文件（保存到 `.tmp` 目录），不负责重新生成文档来替换图片。用户满意图表后自行在 Word 中替换。

**Why:** 用户需要手动调整图片在文档中的位置和大小，自行替换更高效。
**How to apply:** 生成或修改图表后，告知用户 PNG 文件路径即可，不要主动重新生成 .docx 文档。

**Why:** 保持输出目录整洁，只保留最终的 .docx 文档。
**How to apply:** 在用 python-docx 生成文档的脚本执行完毕后，立即删除该脚本文件。

**Why:** 用户需要频繁撰写软著材料等Word文档，统一格式标准保证文档质量和一致性。
**How to apply:** 每次被要求撰写Word文档时，参照此规范设置字体、字号、页面边距和文档结构。使用python-docx库生成.docx文件。生成完毕后自动删除临时脚本。
