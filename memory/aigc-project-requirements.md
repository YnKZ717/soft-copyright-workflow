# AIGC 素材管理与资产库系统 - 项目要求

**Why:** 用户需要按照特定规范撰写软著材料，避免反复沟通相同要求
**How to apply:** 每次为该系统撰写文档时，必须严格遵守以下 6 条要求

---

## 核心要求（6 条）

### 1. 系统职责限制
- 系统**只负责读写平台数据库**
- 源代码文档中**绝对不允许**出现：
  - `CREATE TABLE` 语句
  - 数据库初始化脚本
  - 表结构定义
  - 索引创建语句
  - 任何 DDL（数据定义语言）语句
- 只允许出现：`SELECT`、`INSERT`、`UPDATE`、`DELETE` 等 DML 语句

### 2. 编程语言统一
- 写代码时**尽量用一种编程语言**
- **首选语言：JavaScript**（不是 Java，是 JavaScript）
- 如需其他语言，需用户明确同意
- 示例：Node.js 后端 + Vue.js 前端

### 3. 系统名称规范
- 所有系统名称前必须有 **"Neowow "** 前缀（注意有空格）
- 示例：
  - ✅ "Neowow AIGC 素材管理与资产库系统"
  - ❌ "AIGC 素材管理与资产库系统"
  - ❌ "NeowowAIGC 素材管理与资产库系统"（缺少空格）

### 4. 输出路径控制
- **文本文档**（.docx、.md、.txt 等）：生成后**必须由用户指定输出路径**，不可随意保存
- **图片**（.png、.jpg 等）：可以自行创建 `.tmp` 文件夹保存
- 每次生成文档后，询问用户："请问文档保存到哪个路径？"

### 5. 设计说明书格式
- **不要出现**标题正下方的：
  - 创建日期
  - 编写日期
  - 文档状态（初稿/定稿/修订稿）
  - 密级
  - 版本号（除非用户要求）
- 标题下方直接开始正文内容

### 6. 客户端名称统一
- **绝对不要出现**："Hermes-Agent 客户端"
- **统一使用**："Neowow 内容生成工具平台软件"
- 这个名称在整个文档中保持一致

---

## 检查清单

每次生成文档前，必须检查：
- [ ] 系统名称是否包含"Neowow "前缀？
- [ ] 源代码是否避免了 CREATE TABLE 等 DDL 语句？
- [ ] 编程语言是否统一为 JavaScript？
- [ ] 设计说明书是否去除了标题下方的日期/状态信息？
- [ ] 文档中是否出现"Hermes-Agent"（如有则替换）？
- [ ] 文本文档是否等待用户指定输出路径？
