# 著作权申请表撰写规范

**来源：** 参照 `{{default_output_dir}}/dossier\` 下所有含"著作权申请表"的文档提炼（含4份已填写实例 + 1份空白模板）。

**Why:** 用户需要频繁撰写软著著作权申请表，统一格式、字数、日期逻辑能保证一次通过审核。
**How to apply:** 每次被要求撰写/填写著作权申请表时，必须读取此规范，按字段要求和约束生成内容。

## 〇、表格结构规范（重要！）

**表格格式：两列表格**
- **第一列（标签列）**：项目名称，宽度约 2362 twips（约4.17cm）
- **第二列（内容列）**：具体信息，宽度约 7116 twips（约12.53cm）

**表格对齐：居中**
- 整个表格必须在页面中水平居中

**表格总行数：25行（不含注意事项行）**
- Row 0: 一、软件基本信息（表头，跨全列，蓝色背景 #D9E2F3）
- Row 1-21: 软件基本信息字段（案件编号、软件名称、软件简称、版本号等）
- Row 22: 二、著作权人（表头，跨全列，蓝色背景）
- Row 23-24: 著作权人信息字段

**注意：不包含"请您认真填写表格，提交之后无法修改！"这一行**

**文档结构：**
```
[标题] 计算机软件著作权登记申请表 (微软雅黑/宋体 18pt 加粗 居中)
[副标题] （{软件全称} {版本号}）(宋体 12pt 居中)
[空行]
[说明文字] （可选，9pt 灰色字体）
[表格] （居中）
```

**字体规范：**
- 文档标题：微软雅黑/宋体 18pt 加粗 居中
- 副标题（软件名+版本号）：宋体 12pt 居中
- 表头行：微软雅黑/宋体 12pt 加粗 居中，蓝色背景（#D9E2F3）
- 标签列：宋体 10pt 加粗 左对齐
- 内容列：宋体 10pt 常规 左对齐/两端对齐

**完整行结构：**

## 四、主要功能撰写规范（500-1300字）

### 结构模板

```
[第一段：总体概述，100-200字]
本软件是一款应用于{领域}的{软件类型}，核心功能是{一句话概括核心能力}。
系统采用{技术架构描述}，集成{能力列举}，通过{方式}为用户提供{价值}。

[第二段：功能详细展开，300-900字]
软件的主要功能特点如下：首先，{功能模块1}...；其次，{功能模块2}...；
此外，{功能模块3}...；最后，{功能模块4}...。

[第三段：总结价值，50-150字]
通过上述功能，本软件实现了{总结性成果描述}，
{提升/降低/优化}{具体指标}，
适用于{应用场景列举}等多种场景。
```

### 撰写要点

1. **采用分点叙述**：用"首先...其次...此外...最后..."串联各模块
2. **每个功能模块要具体**：不要只说"支持XX管理"，要展开说明支持哪些具体操作
3. **结尾要有价值总结**：说明软件解决了什么问题、适用于什么场景
4. **必须与说明书和源代码对应**：申请表功能 = 说明书功能 = 源代码实现的功能
5. **语言要专业严谨**：不用口语化表达，不用感叹号

### 已完成的优秀案例参考

- **Neowow Studio**（约550字）：侧重 AI 智能体、云端协作、应用/技能市场
- **内容生产平台**（约1100字）：侧重全链路生产、四大引擎（短片/图片/视频/音频）
- **创作者社区**（约550字）：侧重社群运营、教育学院、虚拟经济、内容审核
- **运营管理后台**（约650字）：侧重后台管理、权限体系、数据运营

## 九、Word文档格式要求

申请表使用 **python-docx** 生成，页面和字体设置：

| 项目 | 设置 |
|------|------|
| 页边距 | 上下左右均约 1cm（EMU: 360045） |
| 文档标题 | 微软雅黑/宋体 18pt 加粗 居中 |
| 副标题 | 宋体 12pt 居中（格式：（{软件全称} {版本号}）） |
| 表格标题行 | 宋体/微软雅黑 12pt 加粗，蓝色背景（#D9E2F3） |
| 表格内容 | 宋体/微软雅黑 10-12pt |
| 表格边框 | 黑色实线，细边框 |

**表格居中和宽度设置（重要！）：**

**方法一：从正确版本复制表格属性（推荐）**

```python
from docx import Document
from lxml import etree

# 读取正确版本
correct_doc = Document(r'{{template_dir}}\著作权申请表 - 最新.docx')
correct_table = correct_doc.tables[0]

# 创建新表格后，复制表格属性
tbl = new_table._tbl
tblPr = tbl.tblPr
if tblPr is None:
    tblPr = OxmlElement('w:tblPr')
    tbl.insert(0, tblPr)

# 从正确版本复制 tblPr
correct_tblPr = correct_table._tbl.tblPr
if correct_tblPr is not None:
    # 清空现有的 tblPr
    for child in list(tblPr):
        tblPr.remove(child)
    
    # 复制所有子元素
    for child in correct_tblPr:
        tblPr.append(etree.fromstring(etree.tostring(child)))
```

**方法二：手动设置表格属性**

```python
def set_table_properties(table):
    """设置表格完整属性（包括居中）"""
    tbl = table._tbl
    tblPr = tbl.tblPr
    if tblPr is None:
        tblPr = OxmlElement('w:tblPr')
        tbl.insert(0, tblPr)
    
    # 1. 设置表格样式
    tblStyle = OxmlElement('w:tblStyle')
    tblStyle.set(qn('w:val'), '33')
    tblPr.append(tblStyle)
    
    # 2. 设置表格宽度为 auto
    tblW = OxmlElement('w:tblW')
    tblW.set(qn('w:w'), '0')
    tblW.set(qn('w:type'), 'auto')
    tblPr.append(tblW)
    
    # 3. 设置居中
    jc = OxmlElement('w:jc')
    jc.set(qn('w:val'), 'center')
    tblPr.append(jc)
    
    # 4. 设置表格边框
    tblBorders = OxmlElement('w:tblBorders')
    for border_name in ['top', 'left', 'bottom', 'right', 'insideH', 'insideV']:
        border = OxmlElement(f'w:{border_name}')
        border.set(qn('w:val'), 'single')
        border.set(qn('w:sz'), '4')
        border.set(qn('w:space'), '0')
        border.set(qn('w:color'), 'auto')
        tblBorders.append(border)
    tblPr.append(tblBorders)
    
    # 5. 设置自动调整布局
    tblLayout = OxmlElement('w:tblLayout')
    tblLayout.set(qn('w:type'), 'autofit')
    tblPr.append(tblLayout)
    
    # 6. 设置单元格边距
    tblCellMar = OxmlElement('w:tblCellMar')
    for margin_name, margin_val in [('top', '0'), ('left', '108'), ('bottom', '0'), ('right', '108')]:
        margin = OxmlElement(f'w:{margin_name}')
        margin.set(qn('w:w'), margin_val)
        margin.set(qn('w:type'), 'dxa')
        tblCellMar.append(margin)
    tblPr.append(tblCellMar)

def set_cell_width_twips(cell, width_twips):
    """设置单元格宽度（twips）"""
    tc = cell._tc
    tcPr = tc.get_or_add_tcPr()
    
    # 移除现有的 tcW
    for tcW in tcPr.findall(qn('w:tcW')):
        tcPr.remove(tcW)
    
    tcW = OxmlElement('w:tcW')
    tcW.set(qn('w:w'), str(width_twips))
    tcW.set(qn('w:type'), 'dxa')
    tcPr.insert(0, tcW)
```

**列宽设置（重要！）：**
- **普通行每列宽度：5553 twips**（约 9.8cm）
- **合并单元格（表头行）宽度：11106 twips**（= 5553 × 2）
- 总宽度：11106 twips（约 19.6cm）

```python
# 设置列宽
for i, row in enumerate(table.rows):
    if i == 0 or i == 22:  # 表头行（合并单元格）
        set_cell_width_twips(row.cells[0], 11106)
    else:  # 普通行
        set_cell_width_twips(row.cells[0], 5553)
        set_cell_width_twips(row.cells[1], 5553)
```

**注意：** 
- 必须在每一行的每个单元格上调用 `set_cell_width_twips()` 设置宽度
- 表头行（Row 0 和 Row 22）是合并单元格，只需要设置一个单元格的宽度
- 推荐使用**方法一**从正确版本复制表格属性，确保格式完全一致
