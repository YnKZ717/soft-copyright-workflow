# 专业术语学习文档生成规范

**触发条件：** 用户提出学习某个专业术语/技术概念时自动触发

## 文档生成流程

### 1. 确认学习深度
询问用户需要的理解程度：
- **入门了解**：知道是什么、干什么用的（最简版）
- **掌握概念**：理解原理、使用场景、与其他概念的关系
- **深入理解**：包含技术细节、实际应用案例、常见问题

### 2. 文档结构（必须包含）

```
封面：术语名称 + "入门指南"/"概念详解"/"深入讲解"
│
├── 一、一句话解释
│   └── 用最通俗的语言解释这是什么
│
├── 二、生活类比
│   └── 用日常生活中熟悉的事物来类比
│
├── 三、核心概念详解
│   ├── 关键术语表格
│   └── 思维导图（文本树形结构）
│
├── 四、使用场景
│   └── 什么时候会用到、在哪里出现
│
├── 五、对比/分类表格
│   └── 与相似概念的对比，或分类说明
│
├── 六、常见问答
│   └── FAQ 形式解答常见疑惑
│
└── 七、总结
    └── 一句话总结 + 全文知识结构思维导图
```

### 3. 格式规范

#### 字体设置
| 用途 | 字体 | 字号 | 加粗 | 对齐 |
|------|------|------|------|------|
| 封面标题 | 宋体 | 36pt | 是 | 居中 |
| 章节标题 | 宋体 | 14pt | 是 | 左对齐 |
| 正文 | 宋体 | 14pt | 否 | 两端对齐 |
| 说明文字 | 微软雅黑 | 12pt | 否 | 左对齐 |
| 思维导图 | Consolas | 10-12pt | 可选 | 左对齐 |

#### 页面设置（说明书标准）
- 上边距：647700 EMU
- 下边距：914400 EMU
- 左边距：575945 EMU
- 右边距：685800 EMU

### 4. 思维导图规范

使用文本树形结构模拟思维导图：
```
主题名称（加粗、蓝色）
│
├── 分支1 ── 说明
│   ├── 子项1
│   └── 子项2
│
├── 分支2 ── 说明
│
└── 分支3 ── 说明
```

规则：
- 使用 Consolas 字体
- 一级分支用 `├──` 和 `└──`
- 连接线用 `│`
- 主标题加粗、蓝色 RGBColor(0, 80, 160)
- 适当使用缩进

### 5. 表格规范

必须包含的表格类型：
- **对比表**：相似概念的横向对比
- **速查表**：关键信息一览
- **场景表**：使用场景列举
- **分类表**：概念的分类说明

表格样式：使用 `Medium Shading 1 Accent 1`
表头加粗、居中
内容字号 10-11pt

### 6. 文件命名规范

格式：`{术语名称}_{文档类型}.docx`，保存到 `{{default_output_dir}}/apprendre\`
示例：
- `API接口_入门指南.docx`
- `微服务架构_概念详解.docx`
- `OAuth认证_深入讲解.docx`

### 7. 代码生成与清理

1. 在 `{{default_output_dir}}/apprendre\` 下创建临时 Python 脚本
2. 使用 `python-docx` 库生成文档
3. 执行脚本生成 .docx 文件
4. **执行完毕后删除临时脚本**
